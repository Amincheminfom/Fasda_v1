## What is this Fasda_v1.0?

<img src="https://github.com/Amincheminfom/Fasda_v1/blob/main/Fasda_logo.jpg" alt="pDILI Logo" width="250" align="right"/>

**Fasda_v1.0** is a web-based tool that allows users to explore the sacffold diversity and molecular profiles.

"Fasda" stands for **F**ingerprint-**a**ssisted **s**caffold **d**iversity **a**nalysis. 
    
It is a <img src="https://streamlit.io/images/brand/streamlit-mark-color.svg" alt="Streamlit Logo" width="50"/>-based [Web Application](https://fasdav1web.streamlit.app/).

Just upload a CSV file with SMILES string to explore Fingerprint-assisted scaffold diversity!

Note: This tool is a part of the article "Structural insights and molecular profiling of a large set of diverse compounds targeting PPARγ: From comprehensive cheminformatics approach to tool development" (SAR and QSAR in Environmental Research, 2025, 36(5), 443–461. DOI: [10.1080/1062936X.2025.2514061](https://doi.org/10.1080/1062936X.2025.2514061)).
